## AI 组是做什么的？

人工智能有很多值得探索的方向。你可以从一个感兴趣的问题出发，逐步找到自己的方向：

- **计算机视觉（Computer Vision）**：让模型从图像和视频中提取信息，尝试图像分类、目标检测、语义分割，也可以研究图像与视频生成。
- **自然语言处理（Natural Language Processing）**：研究语言的表示、理解与生成，从 Transformer 的原理出发，探索语言模型、检索增强生成与多模态交互。
- **语音与音频（Speech and Audio）**：让机器听懂声音、生成语音，尝试语音识别、语音合成、声音转换与音频生成。
- **3D 视觉（3D Vision）**：从图像和点云中恢复三维结构，研究三维重建、场景理解与三维内容生成。
- **具身智能（Embodied AI）**：把感知、决策与行动连接起来，探索机器人如何理解指令、操作物体并完成任务。
- **强化学习（Reinforcement Learning）**：通过与环境交互学习策略，研究奖励设计、策略优化与世界模型。

方向之间也有很多交叉：语言可以连接视觉，世界模型可以服务于决策，生成模型也可以帮助理解三维世界。欢迎带着自己的兴趣探索这些联系。

## 我们怎样学习？

- **打好基础**：在实践中补齐数学、编程和机器学习知识，理解模型背后的基本概念。
- **动手复现**：把论文里的公式与结构变成代码，理清张量形状、训练目标和算法流程。
- **用实验回答问题**：从小规模验证开始，通过对比实验、可视化和错误分析理解模型的行为。
- **交流与记录**：分享读过的论文、踩过的坑和做过的项目，让个人的探索成为大家可以继续积累的经验。
